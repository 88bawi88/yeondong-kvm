# 연동 (Yeondong)

키보드·마우스 하나로 여러 Windows PC를 조작하는 프로그램입니다. 메인 PC 화면 가장자리로 커서를 밀면 옆 PC로 넘어가고, 그때부터 키보드와 마우스 입력이 그 PC로 갑니다. 클립보드(글·그림)는 PC 사이에서 자동으로 맞춰지고, 파일은 탐색기에서 끈 채 화면을 넘어가 놓으면 옮겨집니다.

exe 파일 하나(약 130KB)이고, Windows에 이미 들어 있는 .NET Framework 4.8만 씁니다. 따로 설치할 것은 없습니다.

## 이런 분께 맞습니다

- 마우스를 꽂지 않은 서버나 미니 PC를 데스크탑 키보드·마우스로 조작하고 싶을 때. 마우스가 없는 PC에서도 커서가 보이고, 창 테두리의 크기 조절 모양까지 나옵니다.
- 게임을 하는 PC에서 쓸 때. 커서가 화면 가장자리에 닿기 전에는 입력 훅을 걸지 않고, 게임이 커서를 창 안에 가둬 둔 동안에는 넘어가지 않습니다.

## 시작하기

1. [Releases](https://github.com/88bawi88/yeondong-kvm/releases)에서 `link.exe`를 받아 두 PC에서 각각 실행합니다.
   - 서명되지 않은 프로그램이라 처음에 SmartScreen 경고가 뜹니다. [추가 정보] → [실행]을 누르세요.
   - 실행하면 `%LOCALAPPDATA%\Yeondong\`에 복사되고, 로그인할 때 자동으로 뜹니다.
2. 처음 뜨는 설정 창에서 안내에 동의하고 역할을 고릅니다.
   - 키보드·마우스가 연결된 PC는 **메인 PC**입니다.
   - 조작당할 PC는 **서브 PC**입니다.
3. 짝을 맺습니다. 두 PC 모두 설정 창을 열어 둔 상태여야 합니다.
   - 서브 PC 설정 창에 같은 네트워크의 메인 PC가 나타납니다. 고르고 [짝 맺기]를 누르세요.
   - 목록에 안 보이면 메인 PC의 IP 주소를 직접 적어도 됩니다.
4. 두 PC 화면에 같은 6자리 숫자가 뜹니다. 숫자가 같으면 양쪽에서 [예]를 누릅니다.
5. 메인 PC 트레이 메뉴의 [모니터 배치 정하기]에서 서브 PC 모니터를 원하는 자리에 끌어다 놓습니다. 처음에는 메인 PC의 가장 오른쪽 모니터 옆에 붙어 있습니다.

이미 돌고 있는 상태에서 `link.exe`를 다시 실행하면 설정 창이 열립니다. 트레이 아이콘 메뉴에서도 열 수 있습니다.

## 쓰는 법

- **넘어가기:** 커서를 서브 PC 자리와 맞닿은 화면 가장자리로 밀면 넘어갑니다. 서브 PC 화면에서 메인 PC 쪽 가장자리로 밀면 돌아옵니다.
- **비상 복귀:** `Ctrl+Alt+Home`을 누르면 바로 메인 PC로 돌아옵니다. 연결이 끊겨도 곧바로 돌아옵니다.
- **클립보드:** 한쪽에서 글이나 그림을 복사하면 다른 쪽에서 바로 붙여넣을 수 있습니다(32MB까지). 트레이 메뉴에서 끌 수 있습니다.
- **파일:** 탐색기에서 파일이나 폴더를 끈 채 화면을 넘어가 상대 PC 탐색기에 놓습니다. 넘어갈 때는 이름과 크기만 가고, 놓는 순간 내용을 받아 옵니다. Ctrl+C·Ctrl+V로는 파일을 보내지 않습니다.
- **화면 보기:** 메인 PC 트레이 메뉴의 [<서브 PC> 화면 보기]를 누르면 서브 PC 화면이 창으로 뜹니다. 그 창 위에서 클릭하고 타자를 치면 서브 PC가 그대로 움직입니다. 서브 PC 트레이 메뉴에서 허용을 끌 수 있습니다.
- **공유 폴더 동기화:** 두 PC에서 각각 트레이 메뉴 [공유 폴더 동기화] → [폴더 정하기]로 폴더를 하나씩 정하면, 연결된 동안 두 폴더의 내용이 똑같이 맞춰집니다. 한쪽에 파일을 넣거나 고치거나 지우면 상대 PC에도 바로 반영되고, 지운 파일은 상대 PC에서 휴지통으로 갑니다. 꺼져 있던 동안 바뀐 것은 다시 연결될 때 맞춥니다. [공유 폴더 열기]를 누르면 그 폴더가 탐색기로 열립니다.
- **기능 끄기:** 클립보드, 파일 끌어 놓기, 화면 보기 허용은 트레이 메뉴에서 하나씩 끄고 켭니다.
- **서브 PC 여러 대:** 메인 PC 하나에 서브 PC를 여러 대 짝 맺을 수 있습니다. 서브 PC는 메인 PC 하나와만 짝을 맺습니다.

## 관리자 기능 (선택)

설정 창의 [관리자 기능 설치]를 누르면 관리자 권한으로 다음 일을 합니다.

- `C:\Program Files\Yeondong\`에 설치하고, 그 설치본으로 다시 시작합니다.
- Windows 방화벽에 연동을 허용합니다(개인·도메인 네트워크).
- 입력 도우미 서비스(`YeondongAgent`)를 설치합니다. 서브 PC에서 관리자 권한 창, UAC 확인 창, 잠금 화면까지 조작할 수 있게 됩니다.
- 자동 업데이트는 그때부터 서비스가 맡습니다.

설치하지 않아도 기본 기능은 모두 됩니다. 두 PC 중 한쪽 방화벽만 열려 있어도 연결됩니다. 양쪽이 서로에게 연결을 걸어 보기 때문입니다.

## 보안과 개인정보

- **암호화:** 모든 통신은 TLS 1.2 이상으로 암호화합니다. 각 PC는 처음 실행할 때 자기 인증서를 만들어 Windows 사용자 인증서 저장소에 둡니다.
- **짝 맺기:** 두 화면의 6자리 숫자는 양쪽 인증서와 난수로 계산합니다. 누군가 중간에서 가로채면 두 숫자가 달라지므로, 숫자가 같을 때만 [예]를 누르세요. 짝을 맺은 뒤에는 그때 확인한 인증서를 가진 PC만 연결할 수 있습니다.
- **네트워크 범위:** 사설 주소(192.168.x.x, 10.x.x.x, 172.16~31.x.x)와 링크 로컬 주소에서 오는 연결만 받습니다.
- **보내는 것:** 키보드·마우스 입력, 클립보드 글·그림, 끌어 놓은 파일, 화면 보기 그림, 공유 폴더 파일은 짝 맺은 PC로만 보냅니다. 공유 폴더 동기화는 정해 둔 폴더 바깥을 건드리지 않습니다. 외부 서버로는 아무것도 보내지 않습니다.
- **인터넷 접속:** 새 판 확인을 위해 GitHub API(`api.github.com`)에만 접속합니다. 받은 새 판은 릴리스 서명(ECDSA P-256)이 맞을 때만 설치합니다.

## 알려진 제한

- 서명이 없는 exe라 백신이나 회사 보안 프로그램이 막을 수 있습니다. 입력을 가로채 네트워크로 보내는 동작이 키로거와 비슷해 보이기 때문입니다.
- 메인 PC에서 관리자 권한 창이 앞에 떠 있는 동안에는, 서브로 넘어가도 키 입력이 서브로 가지 않을 수 있습니다.
- 재부팅 직후 로그인 전 화면은 조작할 수 없습니다. 로그인한 뒤의 잠금 화면은 관리자 기능을 설치하면 됩니다.
- Windows끼리만 됩니다.

## 파일 위치

| 무엇 | 어디 |
|---|---|
| 설정(역할, 짝 맺은 PC, 모니터 자리) | `%APPDATA%\Yeondong\config.json` |
| 프로그램과 로그 | `%LOCALAPPDATA%\Yeondong\` (관리자 설치본은 `C:\Program Files\Yeondong\`) |
| 서비스 로그 | `%ProgramData%\Yeondong\` |
| 이 PC 인증서 | 사용자 인증서 저장소(개인), 이름 `Yeondong <id>` |

## 지우기

1. 관리자 기능을 설치했다면 설정 창에서 [관리자 기능 제거]를 먼저 누릅니다.
2. 트레이 메뉴에서 [종료]를 누릅니다.
3. 위 폴더들을 지웁니다.
4. 레지스트리 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`에서 `Yeondong` 항목을 지웁니다.

## 빌드

```powershell
.\build.ps1
```

Windows에 들어 있는 `csc.exe`(.NET Framework 4.x)만 씁니다. 릴리스는 `release.ps1 -Notes <노트 파일>`로 만들며, 서명 키는 저장소에 없습니다.
